# OfTheDay.net — Session 2026-09-11

## Request
From a live iPad screenshot of the Today screen:
1. "The layout is too busy, I don't think we need the 4 boxes that show each thing."
2. "I shouldn't have to scroll down to see the 4 activities."
3. "There were supposed to be more activities added as well — Do Now, ELA, all activities."

## What was actually there
The Today header stacked five separate blocks before the routine ever appeared:
the welcome card (a 3-step onboarding grid), the Friday banner, an eyebrow +
ready line, a hero with a 38px headline and a full descriptive paragraph, the
four `Step 1 Greeting / Step 2 Sharing / …` pills, and a labelled tool-pill row.
At 1024×768 that left ~80px for the routine — one card, partly cut off.

Do Now shipped with `math` and `writing` enabled; `ela`, `science`, and
`socialStudies` were declared in `DO_NOW_SECTIONS` with `enabled: false` and
rendered as greyed-out "Soon" chips with no banks behind them.

`POOL` held 60 activities, but Group Activity and Morning Message had only
**four each** — and those are two of the four `DEFAULT_CATS` the daily routine
draws from, so Shuffle cycled the same handful all week.

## What changed

### Today layout
- Removed the four `.component-pill` step boxes. They restated the numbered
  badge and category label already on each routine card.
- Hero collapsed to one wrapping flex row: short title, the
  `Ready · N components · ~X min · N new to you` line, and the actions.
  The descriptive paragraph is gone.
- `Save for later` moved out of a pinned bottom bar into the hero actions, and
  that bar was deleted. Mobile used to hide the bar entirely, so phones had no
  save button at all — they do now.
- Welcome card dropped its 3-step grid and became a single compact row
  (heading + one line + grade chips).
- Routine cards became a 2×2 grid — `"cat meta" / "title actions"` — about
  76px each instead of 112px.
- Topbar subtitle dropped `Greeting, Sharing, Activity, Message · ~N min`,
  which the hero now states directly below it.

**Trap worth remembering:** the first pass set `min-height: 0` on the compact
cards and they collapsed to 26px, overlapping each other. `.cards-scroll` is a
flex column, so its children shrink to fit unless told not to.
`.cards-scroll > .card { flex-shrink: 0 }` is what actually holds them open.

Verified with Playwright at 1440×900, 1024×768, and 375×812 on `/demo`:
4/4 routine cards fully visible, no horizontal overflow at any width.

### Do Now — ELA, Science, Social Studies
All three enabled with real banks for every grade band (K–2, 3–5, 6–8, 9–12),
four items each, same `{title, problem, hint, answer, teacherNote}` shape as
math and writing — 48 new prompts.

Two supporting refactors so a sixth subject is a one-line change:
- Each `DO_NOW_SECTIONS` entry carries its own `cat`. `doNowToActivity` reads
  `section.cat` instead of a `math ? … : writing ? … : "Brain Teaser"` ternary
  that silently mislabelled everything else.
- `buildContentActivities` iterates every *enabled* subject instead of naming
  math and writing, so new subjects reach the Library on their own.

### Activity pool: 60 → 106
| Category | Before | After |
|---|---|---|
| Greeting | 8 | 18 |
| Sharing | 18 | 30 |
| Group Activity | 4 | 16 |
| Morning Message | 4 | 16 |

Every new id was registered in `GRADE_RITUAL_ACTIVITY_IDS`. That is not
optional: `activityMatchesGrade` resolves against those Sets, so an unregistered
activity is invisible in every grade with no error to explain why.
