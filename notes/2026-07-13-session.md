## hello@oftheday.net — still needs a 10-minute DNS task (owner action)
Mailgun on `mg.oftheday.net` only *sends*. To make `hello@oftheday.net`
*receive*, forwarding must be set up at the domain's DNS host.

**Confirmed 2026-07-13: the domain is registered at NETLIFY** (not Firebase —
Firebase only hosts the site; the A records in Netlify DNS point at it).
Evidence from inbox receipts: Netlify invoice #QRFDUV-00002 (2026-04-28,
$14.99, memo "oftheday.net - expires on 2027-04-28") and the Entri
notification (2026-06-16, "Success! oftheday.net -> Sinch") from when Mailgun
auto-added its sending records to Netlify DNS. Netlify has no built-in email
forwarding, so use ImprovMX (free):

1. app.netlify.com → **Domains** → `oftheday.net` → DNS settings → add:
   - MX record — name: `@` (leave blank/root), value: `mx1.improvmx.com`, priority `10`
   - MX record — name: `@`, value: `mx2.improvmx.com`, priority `20`
   - TXT record — name: `@`, value: `v=spf1 include:spf.improvmx.com ~all`
2. improvmx.com → free account → add domain `oftheday.net` → alias
   `hello` → `dembryllc@gmail.com`. (Optional: catch-all `*` → same inbox.)
3. Wait for ImprovMX to show the domain as verified (usually minutes), then
   email hello@oftheday.net from another account to confirm the forward.

Notes:
- The root domain currently needs no MX conflict check beyond "there should
  be none" — Mailgun's records live on the `mg.` subdomain, so inbound
  forwarding on the root does not affect outbound sending.
- To *reply as* hello@, add it as a "Send mail as" address in Gmail
  (Settings → Accounts) once forwarding works — verification email will
  arrive via the new forward.
- After it works, consider a test: the welcome + lead-magnet emails say
  "Reply to this email", which currently bounces.
